# Drizzy Frontend Client (React.js + Tailwind CSS + Axios + React Router)

High-fidelity frontend reconstruction of Drizzy USA (getdrizzy.co) built as a modular, responsive React single-page application.

## Key Features
- **Accurate Visual Hierarchy**: Uses authentic `Champ Black` display typography, `Azeret Mono`, warm peanut butter cream background (`#f8ebd7`), and rich purple accents (`#2d0f28` and `#ca9af1`).
- **Interactive Squeeze Experience**:
  - Full bottle bundle selector (1x, 2x with 5% savings, 3x [Most Popular] with 7% savings, 6x [Best Value] with 17% savings).
  - One-Time vs Subscribe & Save (10% discount with frequency selection).
  - High-res product media gallery with interactive thumbnails and zoom.
- **Dynamic Slide-Over Cart Drawer & Full Cart**:
  - Live progress meter tracking distance to free shipping ($49.99 threshold).
  - Real-time quantity adjustments, price calculations, and checkout simulation.
- **Interactive Store Locator**:
  - Nationwide stockist directory filtered by city, state, or ZIP code.
  - Sprouts Farmers Market partnership banner and Google Maps directions link.
- **Brand Story & Origins**:
  - Interactive Australian Soul (Queensland) vs American Way (Texas) toggle.
  - Multi-chapter brand timeline with authentic photography.
- **Sprouts Launch Contest Draw**:
  - Form submission with receipt upload for flights to Australia giveaway.
- **Wholesale Inquiries Portal**:
  - Dedicated B2B form for specialty retailers and cafes.
- **Admin Console (`/admin`)**:
  - Protected by backend API key to view orders, inquiries, contest entrants, subscribers, and manage live prices.

## Available Scripts
